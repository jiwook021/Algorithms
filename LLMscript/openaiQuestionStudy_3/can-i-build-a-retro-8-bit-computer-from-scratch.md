Yes, you *can* build a retro 8-bit computer from scratch, but it's a significant undertaking. Let's break it down:

**Step 1: Understanding what you're building:**

An 8-bit computer uses 8 bits (a bit is a 0 or a 1) to process information at a time. This is incredibly simple compared to modern computers, but still requires many components.  Think of it like building a very basic calculator, but you need to create every single part of the calculator yourself, down to the wires.

**Step 2: The components you'll need:**

You won't be using a motherboard, CPU, or RAM like in a modern computer. Instead, you'll need individual components that do the same job, but in a much more primitive way:

* **Central Processing Unit (CPU):**  This is the "brain" of the computer. You'll likely design this using logic gates (tiny switches that perform simple Boolean operations like AND, OR, NOT). You'll need to design the instruction set (the basic operations it can perform).  This is the hardest part.
* **Memory (RAM):**  This stores data the CPU is currently using.  You could use something like simple memory chips, but you'll need to understand how to address (locate specific bits) within the memory.
* **Input/Output (I/O):**  This allows you to interact with the computer. You'll need to design circuits to handle keyboard input, screen output (likely a simple LED display), and potentially other peripherals.
* **Clock:**  This provides the timing signals that synchronize the different components.  A simple oscillator circuit can do this.
* **Power supply:**  You'll need a stable power source to provide the necessary voltage to all the components.


**Step 3: The process:**

1. **Design:** You'll need to design the CPU's architecture, the memory layout, and the I/O interfaces. This requires a deep understanding of digital logic design.
2. **Schematic:**  You'll draw a schematic diagram showing how all the components connect.
3. **Circuit board:** You'll need to create a circuit board (PCB) to physically connect all the components. You can etch your own PCB, or use a PCB fabrication service.
4. **Soldering:** You'll solder all the components onto the PCB.  This requires patience and precision.
5. **Programming:** You'll need to write very basic programs (in machine code or assembly language) to make the computer do anything.

**Step 4: Difficulty:**

This is extremely challenging. It requires advanced knowledge of electronics, digital logic, computer architecture, and programming.  It's more of a large engineering project than a simple hobby.

**Conclusion:**

Technically, yes, you can build a retro 8-bit computer from scratch. But it's a very complex and time-consuming project that's best suited for individuals with a strong background in electronics and computer engineering.  It's much more realistic to start with simpler projects (like building a simple logic gate circuit) before attempting this.  There are kits available that simplify the process, but even those require some level of electronics knowledge.
